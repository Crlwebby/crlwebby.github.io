2024/10/30：

  1. 使用MobaXerm，成功启动了超级玛丽游戏，并且玩了第一关；

  2. 使用命令行ssh -X或者ssh -Y暂未生效：因为XMing（X Client）客户端估计有点问题，设置或者其他问题，导致使用SSH时，没能自动创建远端的$DISPLAY全局变量（指定转发端口）。所以后续遇见使用图形的场景，估计不得不用MobaXterm过渡一下。

  3. 遗留问题1：如何传递声音？Google有人研究过，但是不是我现在的重点。Forward audio from Linux to Windows

  4. 遗留问题2：选择一个合适的x11服务端或客户端，或者干脆全面投入wayland？目前习惯在WSL上进行远端的连接，那势必要在WSL内装上图形化的Server和Client，在物理机上装上Client，然后再在Windows上装上Server。 这样还有一个问题，就是如何启动WSL，就能传递WSL的图形？否则无法传递两层。
